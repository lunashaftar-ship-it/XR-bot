# 🚀 Torino Job Application Dashboard & Automation Tool

A full-stack automation and dashboard tool built to streamline the job and internship search process in Turin, Italy. Designed specifically for targeting tech companies and employment agencies (Agenzie per il Lavoro) with custom application templates.

## 🛠️ Tech Stack & Tools
- **Python**: Core automation and backend logic, SMTP email dispatching, and JobSpy integration.
- **Streamlit**: Interactive web dashboard for managing applications and direct sending.
- **Scikit-Learn (TF-IDF)**: Content-based matching algorithm to score and filter job postings.
- **Pandas**: Data handling and processing.

## ✨ Features
- **Interactive Dashboard**: Clean user interface to view verified Turin tech companies and employment agencies.
- **One-Click Email Dispatch**: Sends professional English applications (tailored for 6-month internships via GOL/Enaip frameworks) along with the applicant's CV.
- **Smart Job Scraping & Matching**: Scrapes live listings and calculates match scores using machine learning techniques.
